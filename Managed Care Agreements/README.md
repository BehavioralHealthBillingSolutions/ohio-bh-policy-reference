# ODM provider-agreement reference excerpts

These are agreements between ODM and managed-care plans. They are not agency-to-payer
participation agreements. **None of these transcriptions is the complete official document.**

Read the [omission register](Excerpts/OMISSIONS.md) first. It explains each version, source link,
excluded page range, and the distinction between PDF viewer numbers and printed page numbers.

- [MCO — July 2026 reference excerpt](Excerpts/Parts/MCO_2026_07/INDEX.md).
- [MyCare — January 2026 reference excerpt](Excerpts/Parts/MyCare_2026_01/INDEX.md).
- [OhioRISE — July 2026 reference transcription](Excerpts/Parts/OhioRISE_2026_07/INDEX.md).

Each file provides the direct official PDF link and original page links. The full PDFs and
omitted Milliman reports are linked only, never included in this repository or its history.
Plain-text extraction does not reliably preserve tables, columns, images, or signatures.
Use the official PDF for exact formatting and complete terms.
