## Format for Subsequent Refresh Reports

Use a dated report with the comparison baseline, section coverage, summary and likely impact for each changed section, full updated statutory text, effective date, official source URL, chapter link, and chapter return link. Distinguish substantive amendments from provisions that were prepublished and later became operative. Preserve dated source snapshots and record their SHA-256 hashes before replacing working copies.
