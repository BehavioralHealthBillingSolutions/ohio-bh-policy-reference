# Public reference workflow

Read [RUNNING_TOOLS.md](RUNNING_TOOLS.md) for device/application/shell labels and [CURATION.md](CURATION.md)
for the publication process. The original rules-comparison tools are under `skills/`.

1. Resolve the exact official source and its effective/proposed/historical status.
2. Retrieve and record source URL, document version, date, and SHA-256.
3. Preserve a dated source copy before updating working law. Never overwrite a historical snapshot.
4. Compare effective law with proposals, or older drafts with newer drafts, explicitly.
5. Write operational interpretation separately from quoted text and identify uncertainty.
6. Validate quotes, tables, page/paragraph references, file links, and hashes. Open a pull request.
7. Maintain [SOURCE_STATUS.md](../SOURCE_STATUS.md) and the publication manifest when new evidence is added.

Full manuals and uncleared third-party documents are publisher links, not public source copies.
Agreement excerpts have a separate omission register; they must never be described as complete.
