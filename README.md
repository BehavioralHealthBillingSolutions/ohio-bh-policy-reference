# Ohio Behavioral Health Policy Reference

Ohio behavioral health rules, proposals, comparison reports, documented agreement excerpts,
and reusable tools maintained by Behavioral Health Billing Solutions, LLC (BHBS).

**This is a curated reference collection. It is not a complete policy library or an official
publication. Agreement transcriptions are not complete official documents.**

| What you need | Where to go |
|---|---|
| Read effective-rule working copies | [Ohio Rules](Ohio%20Rules/README.md). Verify dates against [Ohio Laws](https://codes.ohio.gov/). |
| Explore the existing comparisons | [HTML report set](Ohio%20Rules/Reports_2026-10-13/index.html) and [source/version status](SOURCE_STATUS.md). Download HTML to use it locally; GitHub's file view is not a hosted app. |
| Read provider-agreement reference text | [Agreement excerpts and omissions](Managed%20Care%20Agreements/README.md). |
| Find the complete official manuals | [Manual publisher links](Ohio%20Medicaid%20BH%20Manuals/README.md); full manual copies are not distributed here. |
| Find primary-source links and reuse boundaries | [SOURCES.md](SOURCES.md). |
| Run the tools on your desktop | [docs/RUNNING_TOOLS.md](docs/RUNNING_TOOLS.md). |
| Reproduce the curated build | [docs/CURATION.md](docs/CURATION.md). |
| Suggest a correction | [CONTRIBUTING.md](CONTRIBUTING.md). Never post member data, claims, credentials, or confidential agency documents. |

## Agreement omissions

- July 2026 MCO agreement: PDF viewer pages **363–404** intentionally omitted (Milliman report).
- January 2026 MyCare agreement: PDF viewer pages **336–369** intentionally omitted (Milliman report).
- July 2026 OhioRISE: no Milliman report identified in the reviewed PDF text; completeness is
  not certified. See the individual transcription's disclosure.

Each transcription links to the entire official PDF and each retained original PDF page. The
omission register records the source revision, hashes, page ranges, and explanation. Full
agreement PDFs and excluded pages are not committed anywhere in this repository.

## Read on a phone or desktop

Markdown files can be read in GitHub's browser or mobile app. Use a desktop browser for the
full side-by-side comparison. For offline access select **Code → Download ZIP**, then extract
the ZIP; downloaded copies do not auto-update. Python is needed only to run scripts.
