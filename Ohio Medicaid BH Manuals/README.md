# Official behavioral health manuals — publisher links

Full manual text and PDFs are not distributed in this curated repository while the scope of
public redistribution of embedded CPT content remains unresolved.

- [ODM Manuals, Rates, and Resources](https://medicaid.ohio.gov/resources-for-providers/bh/manuals).
- [Previously released manuals](https://medicaid.ohio.gov/resources-for-providers/bh/information-for-providers/bh-manuals).

If a landing page fails, navigate from the [ODM home page](https://medicaid.ohio.gov/) to its
behavioral health provider resources. Verify the version/date on the original document.
